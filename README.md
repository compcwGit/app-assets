# app-assets

노션 설명서·크몽 등록 자료에 쓰는 이미지 보관 저장소 (공개). 앱마다 `images/앱이름/` 폴더를 쓴다.

- `images/nurse-duty/` — 간호사 근무표 (`app/` 앱 화면, `kmong/` 크몽 이미지, `install-guide.png` 설치 안내)

노션에서는 `https://raw.githubusercontent.com/compcwGit/app-assets/main/images/앱이름/...` 로 링크한다.
설치 파일·자동 업데이트는 앱마다 따로 두는 `앱이름-releases` 저장소를 쓴다.
